# Interactive Quiz Demo

Student starter for the guided HTML, CSS, and JavaScript quiz demo. Work through the template points together during class.

## Run the demo

Open index.html directly in a browser, or use VS Code's Live Server extension. No npm install or build command is needed.

The starter initially shows "Loading question..." until JavaScript is connected. Some interactions are intentionally unfinished.

## What it teaches

- HTML structure and semantic grouping.
- CSS layout and responsive behavior.
- JavaScript events, state, and DOM updates.

The TEMPLATE POINT comments mark the sections we'll work on in class. The rest of the quiz is supplied so we can explore how the parts fit together.

Use the browser's DevTools Console while working. This script uses document and runs in the browser.
